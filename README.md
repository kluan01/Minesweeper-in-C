## Prerequisites
Compiler: -std=c++11 <br>
SFML version: SFML 2.5 <br>
IDE: CLion (optional)<br>

## To Run
1. Ensure SFML and CMake are installed on your machine (via virtual environment if necessary)
2. Clone and navigate to the project directory
3. Build and run the exectuable like below:
```
mkdir build  
cd build  
cmake ..  
make  
./Minesweeper-in-C
```
4. Have fun!
